# ShopFlow delivery intelligence — implementation plan

Spec: docs/superpowers/specs/2026-10-02-shopflow-delivery-intelligence-design.md
Execution: inline, continuous (user approved end-to-end). Each task: tests first where
logic is non-trivial, run, commit.

Global constraints: Python 3.12 for services, **3.8-compatible** for anything imported by
Spark (`weatherops/events.py`, `spark_processor/*`); no new frontend dependencies beyond
maplibre-gl and next/font; secrets never in argv; desktop only.

1. **Rainfall layer** — `weatherops/rainfall.py` (classes, climatology, season), fetch
   script for 2015–2025 daily archive → `data/rain_daily.csv.gz`; sparse hourly replay file
   `data/rain_hourly.csv.gz` from ml/data. Tests: classes, climatology stats, season.
2. **Company network** — `weatherops/company.py`: cities, warehouses, hubs, routes,
   sensitivities, categories, products, ETA/SLA. Tests: relational consistency, BLR → MYS
   numbers, every city reachable by 2 warehouses.
3. **Delay / risk / scenario** — `weatherops/delay.py`, `risk.py`, `scenario.py`.
   Tests: multipliers, contributions sum to score and are bounded, category edges,
   scenario levers move metrics the right way.
4. **Database + seed** — `db/schema.sql`, `seed/` job: master data, weather tables,
   history_daily (vectorised numpy), route_weather_impact, logistic fit. Tests: logistic
   fit recovers coefficients; history aggregates internally consistent.
5. **Event contract + simulator** — `weatherops/events.py`, `simulator/` (clock, demand,
   lifecycle, weather events, faults, Kafka producer). Tests: lifecycle order, delays
   follow truth weather, scheduled orders, duplicates/invalid rates.
6. **Spark job** — rewrite `spark_processor/plans.py` + `streaming_job.py` (quarantine,
   dedup, clean → Kafka, delivery_events → Postgres, 30 s city windows). Tests in Spark image.
7. **Engine** — `serving/engine.py` rewrite: state, KPIs, impact tables, future risk,
   alerts, Redis snapshot/deltas, Postgres upserts, live roll-up, pruning. Tests with fakes.
8. **API** — `serving/api.py` + `serving/queries.py`. Tests: health/overview with
   FakeRedis; SQL endpoints against Postgres when `TEST_PG_DSN` is set.
9. **Local stack** — docker-compose (postgres, seed, simulator, processor, engine, api);
   smoke run end to end.
10. **Dashboard shell** — fonts, tokens, nav, search, status, desktop gate, data layer
    (fetch + WS + demo fallback). Tests: feed reducer, formatters.
11. **Overview page**. 12. **Map page** (states GeoJSON, modes, drill-down).
13. **Future page** (table, timeline, drawer, scenario). 14. **History page** (filters,
    charts).
15. **Deploy** — Postgres manifest, seed job, simulator/processor/engine/api manifests,
    deploy.sh; cloud bring-up; capture demo snapshot; Vercel deploy.
16. **Verify + polish** — browser pass at 1366/1440/1920, console clean, README, memory.
